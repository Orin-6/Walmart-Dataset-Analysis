# Walmart Sales Analysis & Interactive Excel Dashboard

An end-to-end data analysis project using **Microsoft Excel** to explore Walmart sales data, identify business trends, and present key insights through an interactive dashboard.

## 📊 Project Overview

This project focuses on analyzing Walmart sales data using Excel-based data preparation, analysis, and visualization techniques. The interactive dashboard provides a visual overview of sales performance and helps users explore patterns and trends in the dataset.

## 🎯 Project Objectives

- Analyze Walmart sales data to understand sales performance.
- Identify trends and patterns in the available dataset.
- Summarize key metrics for quick interpretation.
- Build an interactive Excel dashboard for data exploration.
- Present data-driven insights through charts and visualizations.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- PivotTables
- PivotCharts
- Excel Formulas
- Data Cleaning and Formatting
- Interactive Dashboard Design
- Slicers and Filters (if implemented)

## ⚙️ Project Workflow

1. **Data Collection** — Load the Walmart dataset into Excel.
2. **Data Preparation** — Review the dataset, check data quality, and prepare the data for analysis.
3. **Data Analysis** — Use Excel formulas and PivotTables to summarize the available data.
4. **Data Visualization** — Create charts to communicate important trends and comparisons.
5. **Dashboard Development** — Arrange key metrics and visualizations into an interactive Excel dashboard.
6. **Insights & Interpretation** — Use the dashboard to explore patterns and support data-driven decisions.

## 📈 Dashboard Highlights

- Key performance indicators (KPIs)
- Sales performance overview
- Category-wise or product-wise analysis, depending on available columns
- Trend analysis using relevant date fields
- Interactive filtering for exploring different segments

## 💡 Key Learning Outcomes

- Practical experience with Excel-based data analysis.
- Understanding of PivotTables and PivotCharts.
- Data cleaning and preparation techniques.
- KPI selection and dashboard layout design.
- Communicating analytical findings through visualizations.
